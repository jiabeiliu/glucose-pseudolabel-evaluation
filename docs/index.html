Glucose Pseudo-label Evaluation

A recorded run of a Python pipeline that learns to reproduce labels generated by K-means clustering. The page explains the experiment and its observed result; it does not execute training or make health predictions in the browser.

Not a diabetes diagnosis or clinical risk score. The CSV contains no observed diabetes outcome label used by this experiment; “accuracy” below means agreement with generated cluster labels only.
01 · SPLITHold out test rows

Training and test data are separated before imputation, scaling, clustering, and PCA.

02 · PSEUDO-LABELFit K-means on training data

The higher-glucose cluster becomes label 1; test labels use the training-fitted clusterer.

03 · EVALUATEStack classifiers

Naive Bayes, KNN, and MLP predictions feed a decision-tree meta learner; score on held-out pseudo-labels.
